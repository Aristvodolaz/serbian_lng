# Support

If something isn't working, if you have a question about the course, or if you want your data deleted, write to [kap.moral22@gmail.com](mailto:kap.moral22@gmail.com).

We usually reply within a few working days. Requests about personal data are handled within the time limits set by [the law](/en/privacy); see section 8 of the privacy policy.

The site has no feedback form: all contact is by email.
