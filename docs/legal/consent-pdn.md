
## Примечания по интеграции (для разработки)

- Факт согласия (отметка чекбокса, дата/время, версия текста политики, на которую пользователь согласился) должен фиксироваться на backend вместе с учётной записью — сейчас в `user.entity.ts` такого поля нет. При включении этого согласия в продакшн стоит добавить `consentGivenAt: Date` и, желательно, `consentPolicyVersion: string`, чтобы иметь возможность доказать факт согласия по запросу Роскомнадзора или пользователя.
- Формулировка «даю согласие» должна быть отделена от согласия с Пользовательским соглашением по смыслу (это два разных документа с разной правовой природой), но их можно объединить в один чекбокс с двумя ссылками, как в варианте A — это стандартная практика.
