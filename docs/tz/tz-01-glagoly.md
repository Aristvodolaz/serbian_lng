# ТЗ-01. Расширение словаря: глаголы (+100)

## 1. Цель

Сейчас в словаре **26 глаголов** — этого недостаточно для построения предложений и упражнений на спряжение. Задача: добавить **100 глаголов** уровня A1 в словарь REČ, заполнив все релевантные для глагола поля и снабдив каждый глагол примером с переводом.

## 2. Результат

1. Файл `words_verbs.csv` (UTF-8) со 100 новыми глаголами, готовый к bulk-импорту в админку.
2. Отчёт о вычитке: подтверждение, что примеры и переводы проверены носителем/редактором.

## 3. Формат строки

Каждая строка — по заголовку:
```
cyrillic,latin,translationRu,translationEn,partOfSpeech,gender,number,declension,conjugation,exampleCyrillic,exampleTranslationRu,exampleTranslationEn
```

### Правила заполнения полей (глагол)

| Поле | Значение | Правило |
|---|---|---|
| `cyrillic` | инфинитив | на сербской кириллице, e.g. `радити`, `читати` |
| `latin` | транслитерация инфинитива | официальная сербская латиница, e.g. `raditi` |
| `translationRu` | перевод инфинитива | на русском |
| `translationEn` | перевод инфинитива | на английском |
| `partOfSpeech` | `verb` | обязательно |
| `gender` | ⛔ | пусто |
| `number` | ⛔ | пусто |
| `declension` | ⛔ | пусто |
| `conjugation` | `I` / `II` / `III` | по окончанию 1-го лица ед. числа, см. ниже |
| `exampleCyrillic` | предложение с глаголом | кириллица, см. правила примера |
| `exampleTranslationRu` | перевод предложения | русский |
| `exampleTranslationEn` | перевод предложения | английский |

### Определение типа спряжения

Тип определяется по окончанию 1-го лица единственного числа настоящего времени:

| Код | Окончание | Примеры |
|---|---|---|
| `I` | **-ам** | читати → читам, знати → знам, играти → играм, певати → певам, спавати → спавам |
| `II` | **-ем / -ујем** | звати се → зовем се, ићи → идем, јести → једем, пити → пијем, путовати → путујем, куповати → купујем |
| `III` | **-им** | радити → радим, говорити → говорим, живети → живим, волети → волим, будити се → будим се |

Исключения (глагол `бити` и нестандартные) — `conjugation` оставлять пустым, пометить строку комментарием в отчёте.

**Распределение по типам:** не менее ~25 на каждый тип (`I/II/III`), чтобы в уроках было разнообразие. Не допускается класть все 100 в `III`.

## 4. Тематическое наполнение (ориентир)

Глаголы уровня A1 по семантическим группам (это ориентир, не жёсткий список; цель — 100 шт.):

| Группа | Примеры (серб. инф.) | Кол-во |
|---|---|---|
| Движение и поездки | ићи, доћи, отићи, доћи кући, вратити се, трчати, ходати, возити, летети, стати | ~10 |
| Ежедневные действия | устати, јести, пити, спавати, радити, одмарати се, отворити, затворити, оставити, узети | ~10 |
| Речь и коммуникация | рећи, питати, одговорити, причати, чути, слушати, читати, писати, звати, поздравити | ~10 |
| Восприятие и знание | видети, гледати, знати, учити, разумети, мислити, памтити, изгледати, осећати, размишљати | ~10 |
| Желания и возможности | хтети, моћи, морати, требати, желети, моћи се, усети, успети, сумњати, надати се | ~10 |
| Покупки и деньги | купити, платити, коштати, продавати, тражити, наћи, мењати, враћати, дуговати, штедети | ~10 |
| Эмоции и состояния | волети, свидети се, бојати се, смејати се, плакати, љутити се, радовати се, умрети, одморити, бринути | ~10 |
| Еда и приготовление | кувати, пећи, јести, пити, пробати, сећи, сипати, наручити, послужити, доручковати | ~8 |
| Рефлексивные (- се) | звати се, будити се, купати се, облачити се, смејати се, бојати се, надати се, догодити се, осећати се, вратити се | ~8 (могут пересекаться с группами выше) |
| Прочее A1 | бити, имати, излазити, улазити, почињати, завршавати, чекати, шетати, пливати, играти, певати, слушати | ~12 |

Итого по ориентиру ≈ 100. Список не обязан совпадать дословно: главное — уровень A1, частотность и покрытие тем существующих юнитов (дом, еда, путешествия, люди, время).

**Запрещено дублировать** глаголы, уже есть в словаре: радити, живети, говорити, звати се, будити се (проверять по `words_with_fields.csv`).

## 5. Правила примера

- Предложение на сербском (кириллица), до ~8 слов, настоящее время.
- Глагол в примере — в **спрягаемой форме** (не инфинитив), чтобы было видно спряжение: `Ја читам књигу.`, `Она говори српски.`, `Ми идемо у град.`
- Для рефлексивных — форма с `се` в правильном месте: `Ја се будим у седам.`
- `exampleTranslationRu/En` переводят именно предложение, согласованы между собой.

## 6. Критерии приёмки

- 100 строк, все поля по матрице ТЗ-01 заполнены (пусты только `gender`/`number`/`declension`).
- `conjugation` — только `I/II/III` или пусто (для исключений, с отметкой в отчёте); распределение ≥25/25/25 по трём типам.
- Ни одного дубля `cyrillic` ни между собой, ни с существующими словами.
- Латиница корректна (ђ→đ, ћ→ć, љ→lj, њ→nj, џ→dž, ш→š, ж→ž, ч→č, ц→c, ј→j).
- Все примеры проверены: сербский без латинских вкраплений, RU/EN-переводы согласованы.
- CSV проходит bulk-импорт админки без ошибок валидации.
