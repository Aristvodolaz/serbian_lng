## Формат поставки данных (общий для всех ТЗ)

CSV в кодировке **UTF-8**, первая строка — заголовок. Заголовки и значения — точно как в существующих файлах. CSV загружаются через админ-панель (юниты/уроки/слова — UI или bulk upload, упражнения — bulk upload).

### Слово (`words`)

Заголовок:
```
cyrillic,latin,translationRu,translationEn,partOfSpeech,gender,number,declension,conjugation,exampleCyrillic,exampleTranslationRu,exampleTranslationEn
```

Контролируемые значения атрибутов (коды — строго из словаря админки):

| Поле | Допустимые значения | Когда заполнять |
|---|---|---|
| `partOfSpeech` | `noun, verb, adjective, adverb, pronoun, preposition, conjunction, particle, interjection, numeral` | всегда |
| `gender` | `m` (муж.), `f` (жен.), `n` (ср.) | у слов, имеющих род |
| `number` | `singular`, `plural` | у слов, имеющих число |
| `declension` | `I` (м/ср), `II` (ж на -а), `III` (ж на согласный) | у существительных |
| `conjugation` | `I` (-ам), `II` (-ем/-ујем), `III` (-им) | у глаголов |

### Матрица «часть речи → какие поля заполнять»

Поле = ✅ обязательно, ⛔ неактуально (оставить пустым), ◻ по правилу из ТЗ.

| Поле | noun | verb | adjective | adverb | pronoun | prep/conj/particle | numeral |
|---|---|---|---|---|---|---|---|
| `cyrillic` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| `latin` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| `translationRu` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| `translationEn` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| `partOfSpeech` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| `gender` | ✅ | ⛔ | ✅ | ⛔ | ◻ | ⛔ | ◻ |
| `number` | ✅ | ⛔ | ✅ | ⛔ | ◻ | ⛔ | ◻ |
| `declension` | ✅ | ⛔ | ⛔ | ⛔ | ⛔ | ⛔ | ⛔ |
| `conjugation` | ⛔ | ✅ | ⛔ | ⛔ | ⛔ | ⛔ | ⛔ |
| `exampleCyrillic` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| `exampleTranslationRu` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| `exampleTranslationEn` | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

Пояснения к «◻» (см. соответствующие ТЗ):
- **pronoun**: `gender`/`number` заполняются, если форма местоимения их несёт (он/она/оно, possessives, числовые формы), иначе пусто.
- **numeral**: `gender`/`number` заполняются у числительных, которые их имеют (`један`, `два`), иначе пусто.

### Урок (`lessons`)

Заголовок:
```
unitTitle,title,titleLatin,titleTranslationRu,titleTranslationEn,xpReward
```
`unitTitle` — кириллический заголовок юнита (как в `units.csv`). `xpReward` — 10 (стандарт).

### Юнит (`units`)

Заголовок:
```
titleCyrillic,titleLatin,titleTranslationRu,titleTranslationEn
```

### Упражнение (`exercises`)

Заголовок:
```
type,unitTitle,lessonTitle,cyrillic,latin,translationRu,translationEn,audioUrl,imageUrl,sentenceCyrillic,sentenceLatin,sentenceTranslationRu,sentenceTranslationEn
```

- `type` — `translation_choice` (выбор перевода) или `fill_word` (вставка слова).
- `cyrillic`..`translationEn` — слово из словаря (ссылка на существующий словарный вход).
- `audioUrl`/`imageUrl` — пусто (не заполняем, нет контента).
- `sentenceCyrillic`/`sentenceLatin`/`sentenceTranslationRu`/`sentenceTranslationEn` — предложение-пример **только для `fill_word`**; для `translation_choice` — пусто.
- Латиница (`latin`, `sentenceLatin`) — официальная сербская транслитерация, не подстрочный перевод.

## Общие правила качества (применимы ко всем ТЗ)

1. **Язык примеров** — A1. Предложения короткие (до ~8 слов), лексика из изученного или очевидная, без идиом и сложных конструкций. Глагольные примеры — в основном настоящее время.
2. **Точность перевода** — `translationRu` и `translationEn` переводят *само слово*, а `exampleTranslationRu/En` переводят *предложение*, не по словам. Русский и английский переводы предложения должны соответствовать друг другу и сербскому оригиналу.
3. **Грамматика** — кириллица и латиница строго на сербском, без вкраплений латинских букв в кириллицу (и наоборот). Коды `gender/number/declension/conjugation` — только из словаря админки.
4. **Уникальность** — `cyrillic` не должен дублировать существующие слова (проверять по `words_with_fields.csv`). Транслитерация `latin` соответствует сербскому алфавиту (ђ→đ, ћ→ć, љ→lj, њ→nj, џ→dž, ш→š, ж→ž, ч→č, ц→c, ј→j).
5. **Никаких пустых обязательных полей** — если поле помечено ✅ в матрице, оно заполнено у каждой строки.
6. **Статусы** — новые/изменённые записи создаются как черновики (`draft`) и публикуются только после прохождения ТЗ-04 (аудита).

## Критерии приёмки (общие)

- CSV парсится bulk-импортом админки без ошибок валидации.
- Каждая строка прошла проверку по матрице полей (нет пустых ✅, нет заполненных ⛔).
- Слова уникальны по `cyrillic` и не конфликтуют с существующими.
- Все переводы и примеры проверены носителем/редактором; отчёт о вычитке приложен.
