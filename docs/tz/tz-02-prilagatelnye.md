# ТЗ-02. Расширение словаря: прилагательные (+100)

## 1. Цель

Сейчас в словаре **36 прилагательных** — мало для описания предметов и людей и для уроков вроде «Придеви» и «Боје». Задача: добавить **100 прилагательных** уровня A1, заполнив поля рода и числа (актуальные для прилагательных) и снабдив каждое примером с переводом.

## 2. Результат

1. Файл `words_adjectives.csv` (UTF-8) со 100 новыми прилагательными, готовый к bulk-импорту в админку.
2. Отчёт о вычитке: подтверждение, что примеры и переводы проверены носителем/редактором.

## 3. Формат строки

Заголовок (тот же, что у слов):
```
cyrillic,latin,translationRu,translationEn,partOfSpeech,gender,number,declension,conjugation,exampleCyrillic,exampleTranslationRu,exampleTranslationEn
```

### Правила заполнения полей (прилагательное)

| Поле | Значение | Правило |
|---|---|---|
| `cyrillic` | **форма мужского рода ед. числа** (словарная форма) | e.g. `добар`, `леп`, `велики`, `црн` |
| `latin` | транслитерация | `dobar`, `lep`, `veliki`, `crn` |
| `translationRu` | перевод (м.р.) | e.g. `добрый` |
| `translationEn` | перевод | e.g. `good` |
| `partOfSpeech` | `adjective` | обязательно |
| `gender` | `m` | у словарной формы (мужской род ед. числа) |
| `number` | `singular` | словарная форма |
| `declension` | ⛔ | пусто (схема склонений I/II/III в приложении определена для существительных; у прилагательных из-за определённого/неопределённого вида она не применяется) |
| `conjugation` | ⛔ | пусто |
| `exampleCyrillic` | предложение, где прилагательное согласуется с существительным | кириллица |
| `exampleTranslationRu` | перевод предложения | русский |
| `exampleTranslationEn` | перевод предложения | английский |

## 4. Тематическое наполнение (ориентир)

Прилагательные уровня A1 по группам (ориентир, не жёсткий список; цель — 100 шт.):

| Группа | Примеры (серб. м.р.) | Кол-во |
|---|---|---|
| Антонимы-пары размера/качества | велики/мали, висок/низак, дуг/кратак, широк/узак, тежак/лак, дебео/мршав, брз/спор, јак/слаб | ~16 |
| Оценка и состояние | добар/лош, леп/ружан, нов/стар, млад/стар, срећан/тужан, богат/сиромашан, здрав/болестан, уморан/одморан | ~16 |
| Цвета | црн, бео, жут, браон, сив, љубичаст, наранџаст, розе, златан, сребрн | ~10 |
| Ощущения и свойства | топао/хладан, врућ, мек/тврд, сув/мокар, чист/прљав, свеж, сладак/слан/кисео/горак, љут | ~14 |
| Внешность и характер | висок, низак, млад, стар, згодан, леп, паметан, глуп, добар, љубазан, стрпљив, нервозан, срамежљив, дружељубив | ~14 |
| Национальности и языки | руски, енглески, немачки, француски, италијански, шпански, грчки, кинески, амерички | ~9 |
| Погода и природа | сунчан, облачан, кишовит, ветровит, хладан, топао, снежан, топао/врућ, светао, таман | ~10 |
| Время и порядок | први, последњи, следећи, исти, други, самосталан, главни, слободан, заузет, заједнички | ~10 |

Итого по ориентиру ≈ 99–100. Список не обязан совпадать дословно; важны уровень A1 и частотность.

**Запрещено дублировать** прилагательные, уже есть в словаре: широк, дуг, млад, стар, висок, низак, добар, лош, нов, велики, мали, леп, црвен, плав, зелен, тешко (проверять по `words_with_fields.csv`; `тешко` в словаре — наречие, прилагательное `тежак` добавить можно).

## 5. Правила примера

- Предложение на сербском, до ~8 слов, где прилагательное стоит в согласованной с существительным форме (по роду/числу существительного), например:
  - `Ово је лепа кућа.` (женский род)
  - `Имам малу собу.`
  - `Данас је хладан дан.`
- В `exampleCyrillic` прилагательное может стоять в любой форме (не только м.р.) — словарный вход фиксирует базовую форму в `cyrillic`, а пример показывает согласование.
- RU/EN-переводы — полные переводы предложений, согласованные между собой.

## 6. Критерии приёмки

- 100 строк, все поля по матрице ТЗ-02 заполнены (пусты только `declension`/`conjugation`).
- `gender`=`m`, `number`=`singular` у всех строк (словарная форма).
- Ни одного дубля `cyrillic` ни между собой, ни с существующими словами.
- Латиница корректна (ђ→đ, ћ→ć, љ→lj, њ→nj, џ→dž, ш→š, ж→ž, ч→č, ц→c, ј→j).
- Все примеры проверены: сербский без латинских вкраплений, согласование прилагательного с существительным верное, RU/EN-переводы согласованы.
- CSV проходит bulk-импорт админки без ошибок валидации.
