# ТЗ-05. Составление дополнительных уроков

## 1. Цель

Привести уроки к целевому состоянию: **30 уроков в 8–10 юнитах**, каждый урок — **8–12 слов**, без «пустых» (3 слова) и перегруженных (30 слов) уроков. Задача выполняется **после/параллельно** с ТЗ-04 (аудит) и ТЗ-01…03 (расширение словаря) и опирается на их результаты: аудит даёт список пустых уроков, словарь даёт слова для наполнения.

## 2. Что нужно сделать (три подзадачи)

1. **Дополнить пустые уроки** (по результатам ТЗ-04: сейчас 6 уроков по 3–4 слова) до 8–12 слов.
2. **Добавить новые уроки** в существующие юниты, чтобы довести общее число до ~30.
3. *(Опционально)* Добавить **1–2 новых юнита** (например, «Природа», «Покупка»), только если для них хватает слов в расширенном словаре; базово для MVP достаточно 8 существующих юнитов.

## 3. Правила составления урока

### 3.1 Слова

- **Источник слов — только словарь** (существующие + добавленные по ТЗ-01…03). Новые слова в рамках ТЗ-05 не придумываются; если для урока не хватает слов — это сигнал для ТЗ-01…03.
- **Размер урока: 8–12 слов.** Жёстко: не меньше 6, не больше 15.
- Приоритет: сначала использовать слова, ещё не задействованные в уроках (`ORPHAN_WORD` из ТЗ-04), затем повторное использование.
- Повторное использование слова в другом уроке **допускается** (нет ограничения в модели), но не злоупотреблять: одно и то же слово максимум в 2 уроках, иначе уроки сливаются.
- Слова урока должны быть **тематически связаны** с уроком и юнитом (см. п. 4).
- Соотношение частей речи в уроке — сбалансированное: урок не из одних существительных; в уроках на «тему» (еда, город) норма — ~60–70% существительных + глаголы/прилагательные/наречия; в уроках-грамматике (глаголы, прилагательные) — соответствующая часть речи.

### 3.2 Упражнения

- На каждое слово урока — **2 упражнения**: `translation_choice` + `fill_word` (единый паттерн, как сейчас).
- Итого урок = 16–24 упражнения (при 8–12 словах).
- `translation_choice`: вопрос — слово из словаря (RU/EN переводы), варианты — переводы.
- `fill_word`: `sentenceCyrillic`/`sentenceLatin` — предложение-пример из словарного входа слова, в котором это слово пропущено; варианты — сербские слова; `sentenceTranslationRu/En` — перевод предложения.
- Предложения `fill_word` не должны раскрывать правильный ответ в переводе или в других вариантах (без подсказок типа одинаковых корней в вариантах).

### 3.3 Оформление урока и юнита

- `title` (кириллица) + `titleLatin` + `titleTranslationRu` + `titleTranslationEn` — у каждого нового урока.
- `unitTitle` в CSV — точный кириллический заголовок существующего юнита (`units.csv`).
- `xpReward` = 10.
- **Порядок:** новые уроки встают в конец своего юнита; `order` юнитов и уроков непрерывен (нет дыр). Если юнит новый — он добавляется в конец списка юнитов.
- Урок не должен дублировать название существующего (уникальна пара «юнит+урок»).

## 5. Результат и доставка

1. Обновлённые `lessons.csv` (все уроки: старые + новые) и `exercises.csv` (упражнения для всех слов всех уроков).
2. Новые слова, если потребовались, — в файлы по ТЗ-01…03 (не внутри ТЗ-05).
3. Отчёт: какие уроки добиты, какие добавлены, какие юниты затронуты; подтверждение, что все уроки в диапазоне 8–12 слов и каждый урок — 2 упражнения на слово.

## 6. Критерии приёмки

- Общее число уроков = **30** (или согласовано иначе), все в диапазоне **8–12 слов** (жёстко 6–15).
- Каждый урок: 16–24 упражнения, ровно 2 на слово; типы — только `translation_choice` + `fill_word`.
- Все слова уроков существуют в словаре и тематически относятся к уроку/юниту.
- Уроки и юниты: заголовки RU/EN и латиница заполнены, `xpReward`=10, порядок непрерывен, названия уникальны.
- CSV проходит импорт админки без ошибок валидации.
- Результаты ТЗ-04 по прежним пустым урокам закрыты (нет `EMPTY_LESSON` со статусом ❌).
