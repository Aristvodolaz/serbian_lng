# ТЗ-03. Расширение словаря: наречия (+100) и служебные слова (+~50)

## 1. Цель

Сейчас в словаре **23 наречия**, **7 местоимений**, **4 предлога**, **1 союз**. Служебные слова и наречия — каркас любого предложения, без них невозможно составить естественные примеры и упражнения. Задача в двух частях:

- **Часть A.** Добавить **100 наречий** уровня A1.
- **Часть B.** Добавить **~50 служебных слов**: местоимения, предлоги, союзы, частицы, междометия (+ точечно числительные, у которых заполняются род/число).

## 2. Результат

1. `words_adverbs.csv` — 100 наречий.
2. `words_function.csv` — ~50 служебных слов.
3. Отчёт о вычитке примеров и переводов.

## 3. Формат строки

Оба файла — один и тот же заголовок слов:
```
cyrillic,latin,translationRu,translationEn,partOfSpeech,gender,number,declension,conjugation,exampleCyrillic,exampleTranslationRu,exampleTranslationEn
```

### Правила заполнения полей

#### Наречие (`partOfSpeech = adverb`)

| Поле | Правило |
|---|---|
| `cyrillic` | наречие, e.g. `често`, `овде`, `веома` |
| `latin` | транслитерация |
| `translationRu/En` | перевод наречия |
| `gender`, `number`, `declension`, `conjugation` | ⛔ пусто (наречие неизменяемо) |
| `exampleCyrillic` + переводы | предложение с наречием |

#### Служебные слова

| Часть речи | `gender` | `number` | `declension` | `conjugation` |
|---|---|---|---|---|
| `pronoun` | ◻ заполнить, если форма несёт род (`он`→m, `она`→f, `оно`→n; possessives `мој`→m); иначе пусто (`ја`, `ти`, `ми`, `ви`, `ко`, `шта`) | ◻ заполнить, если форма несёт число (`ја`→singular, `ми`→plural, `он`→singular); иначе пусто | ⛔ | ⛔ |
| `preposition` | ⛔ | ⛔ | ⛔ | ⛔ |
| `conjunction` | ⛔ | ⛔ | ⛔ | ⛔ |
| `particle` | ⛔ | ⛔ | ⛔ | ⛔ |
| `interjection` | ⛔ | ⛔ | ⛔ | ⛔ |
| `numeral` | ◻ у числительных, имеющих род (`један`→m, `два`→m), иначе пусто | ◻ `један`/`два`→singular, иначе пусто | ⛔ | ⛔ |

Общий принцип: **служебное слово неизменяемое — все атрибуты пустые; если форма несёт род/число — заполняем.**

## 5. Правила примера

- Предложение до ~8 слов, с наречием/служебным словом в естественной позиции:
  - наречие времени: `Он често иде у парк.`
  - место: `Књига је на столу.` (предлог), `Кућа је близу.` (наречие)
  - союз: `Волим кафу, али не пијем чај.`
  - частица/местоимение: `Ко је то?`, `Ово је моја књига.`
- Для местоимений пример показывает форму в контексте; для предлогов — с существительным (падежное управление).
- RU/EN-переводы — полные переводы предложений, согласованные между собой.

## 6. Критерии приёмки

- 100 наречий + ≥50 служебных; все поля по матрице ТЗ-03 заполнены, пусты только помеченные ⛔.
- `gender`/`number` у местоимений и числительных заполнены только там, где форма их несёт.
- Ни одного дубля `cyrillic` ни между файлами, ни с существующими словами.
- Латиница корректна (ђ→đ, ћ→ć, љ→lj, њ→nj, џ→dž, ш→š, ж→ž, ч→č, ц→c, ј→j).
- Примеры проверены: сербский без латинских вкраплений, предлоги с правильным падежом, RU/EN-переводы согласованы.
- Оба CSV проходят bulk-импорт админки без ошибок валидации.
