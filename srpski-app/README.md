# srpski-app

Приложение для изучения сербского языка русскоязычными. Два нативных клиента —
iOS на Swift и Android на Kotlin — плюс общий контент-пайплайн в этом репозитории.

Курс: русский → сербский, белградская норма, экавица.

## Текущее состояние

Готов контент-пайплайн и первый юнит целиком: 4 урока, 47 лексем, 43 предложения,
32 сгенерированных упражнения. Клиенты ещё не начаты.

## Быстрый старт

```bash
make            # проверить источники и собрать курс
make audio      # черновая озвучка для разработки (только macOS)
```

Требуется Python 3.9+ без внешних зависимостей.

`make audio` обращается к системному синтезатору речи и AAC-кодеку, поэтому
работает только при запуске напрямую в терминале — в изолированных окружениях и
CI кодек недоступен.

## Структура

```
content/
  course.json      структура курса и грамматические заметки
  lexemes.csv      словарь: леммы, переводы, словоформы
  sentences.csv    предложения с переводами
  stoplist.csv     хорватизмы и иекавица, которые ловит валидатор
  SCHEMA.md        контракт контента для клиентов
  build/           генерируется, в гит не попадает
tools/
  content.py            загрузка источников, индексы словоформ и фраз
  transliterate.py      латиница → кириллица
  validate_content.py   проверки, блокирующие сборку
  build_content.py      сборка JSON для клиентов
  make_dev_audio.py     черновая озвучка
```

## Ключевые решения

**Латиница — источник истины, кириллица генерируется.** Сербский использует оба
алфавита, соответствие однозначное. Хранить обе формы вручную — значит держать
два источника правды и рассинхронизировать их. Транслитератор учитывает стык
морфем: `nadživeti` → `надживети`, а не `наџивети`.

**Упражнения генерируются при сборке, а не в приложении.** Клиенты получают
готовые списки вариантов с уже вычисленным правильным индексом. Это убирает
главный источник расхождений между iOS и Android и снимает с обеих команд
изрядный кусок логики. Любая случайность засеяна `id` упражнения, поэтому
сборка воспроизводима: одинаковый вход даёт одинаковый выход.

**Валидатор — главный инструмент против плохого AI-контента.** Он ловит
хорватизмы (`kruh`, `tisuća`, `tko`) и иекавицу (`mlijeko`, `lijep`, `gdje`) по
стоп-листу, отсутствие рода у существительных и вида у глаголов, а главное —
предложения, которые опираются на лексику из более поздних уроков. Последняя
ошибка самая коварная: фраза выглядит естественно, но требует слов, которых
пользователь ещё не видел.

**Прогресс пользователя привязан к `id` лексемы.** Меняя `id`, вы обнуляете
прогресс по этому слову у всех. Текст и перевод править можно свободно.

## Что дальше

Прежде чем масштабировать контент, нужно закрыть три вещи. Первая — вычитка
носителем: сейчас формы и падежи в предложениях никем не проверены, а валидатор
ловит только словарные расхождения, не грамматические. Вторая — продакшн-озвучка,
потому что системного сербского голоса не существует и черновая хорватская речь в
релиз не годится. Третья — клиенты: контракт `content/SCHEMA.md` заморожен и обе
команды могут начинать параллельно.

Роадмап по версиям — в отдельном канвасе `serbian-app-roadmap`.
